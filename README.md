# VA Claim Tracker

A free, open source Firefox extension that gives veterans a clearer view of their VA disability claim status — all in one clean popup.

**Not affiliated with the U.S. Department of Veterans Affairs.**

## Features

- Visual phase progress bar across all 7 claim phases
- Estimated completion date range
- Full list of claimed conditions
- Supporting documents with upload dates
- Status flags — documents needed, letters sent
- Notifies you of phase or date changes when you open the popup
- Fetches fresh data every time you open it — no manual refresh needed

---

## Installation

1. Install the extension from the [Firefox Add-ons Store](https://addons.mozilla.org/firefox/addon/va-claim-tracker)
2. Log into [VA.gov](https://www.va.gov)
3. Navigate to **Claims and Appeals** and open your claim status page
4. Click the VA Claim Tracker icon in your toolbar

---

## Privacy

This extension collects no user data. All claim information is fetched directly from VA.gov's API using your existing browser session and stored locally on your device only. No data is transmitted to any third party. The only server this extension communicates with is `api.va.gov` — the same server your browser already talks to when you load your claim page.
